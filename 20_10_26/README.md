# Schreinerei Meier

Statische Website der Schreinerei Meier. Das Projekt stellt Informationen zu Leistungen, Preisen, Holzarten, Möbeln und Kontaktdaten bereit.

## Seiten

- `index.html` - Startseite mit Leistungen und Geschichte
- `preise.html` - Preisübersicht
- `holzarten.html` - Informationen zu Schweizer Holzarten und Holzgewicht
- `gallery.html` - Galerie mit Möbelbeispielen
- `kontakt.html` - Adresse, Mitarbeiter und Kontaktmöglichkeiten

## Technologien

- HTML5
- CSS3
- SVG-Grafiken

## Lokales Ansehen

Das Projekt benötigt keine Installation oder Build-Tools. Öffne die Datei `index.html` direkt im Browser oder starte einen lokalen Webserver:

```powershell
python -m http.server 8000
```

Danach ist die Website unter `http://localhost:8000` erreichbar.

## Projektstruktur

```text
.
|-- index.html
|-- preise.html
|-- holzarten.html
|-- gallery.html
|-- kontakt.html
|-- style.css
|-- layout.css
`-- img 2/
    |-- chair.svg
    |-- cupboard.svg
    |-- desk.svg

```

Die SVG-Dateien werden auf der Galerieseite verwendet.

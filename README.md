Repository for storing school projects, notes, and source code as part of my **Applikationsentwickler EFZ** apprenticeship.

## Repository Structure

- **`/date`** — School day in which the file was created.

## Tech Stack & Tools

The materials in this repository cover the technologies used during my studies and independent practice:

- **Languages & Frameworks:** Python (incl. PyQt6, CustomTkinter), JS, HTML/CSS, C++ (Arduino).
- **Environment:** Windows, WSL2 (Ubuntu), Visual Studio Code.
- **Version Control:** Git, GitHub.
